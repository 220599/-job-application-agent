## Audit findings (done)
- Real flow (`packages/greenhouse/src/adapter.ts` `submitRealGreenhouseForm`): navigate -> scan (challenge gate) -> fill (in-page script) -> uploadResumeFile -> rescan (challenge gate) -> submit click -> poll confirmation -> interpret. Failures before submit click = definitive not-submitted; after = SUBMISSION_UNCONFIRMED (never retried).
- `packages/greenhouse/src/real-submission.ts`: `buildFillGreenhouseFormScript` (native value setter; SELECT branch guarded for non-native selects -> missed), `buildSubmitGreenhouseFormScript`, `buildReadGreenhouseConfirmationScript`, `interpretGreenhouseConfirmation` (conservative asymmetric-safe verdicts).
- Field mapping (`adapter.ts` `mapFieldKindToType`): react-select 'combobox' maps to 'SELECT', so fills cannot distinguish native select vs react-select; comboboxes currently end up `missed`.
- React Select: `captureComboboxOptions` (inspect) already does click -> read `readOpenDropdownOptions` -> `closeOpenDropdown` via JaaPage. No fill path exists.
- Iframe limitation: all scan/fill/submit runs in main frame (`JaaPage.evaluate` = `pwPage.evaluate`). Custom-domain boards (e.g. careers.formlabs.com) embed the form in `#grnhse_iframe` -> `job-boards.greenhouse.io/embed/job_app?...`; form invisible to adapter.
- CAPTCHA timing gap: first scan runs ~0.4s after navigate; async reCAPTCHA Enterprise (recaptcha.net anchor + `[name=g-recaptcha-response]`) may not be in DOM yet -> gate can miss it. Need settle/poll before the pre-submit rescan.
- No-retry-on-unknown is already well architected: `submission-handler.ts` classifies `SUBMISSION_UNCONFIRMED` -> `SUBMISSION_OUTCOME_UNKNOWN, retryable:false`; `application-submission.ts` durable attempt ledger (unresolved SUBMISSION_STARTED blocks any new attempt); covered E2E by `apps/api/tests/e2e/submission-safety-e2e.test.ts` crash-retry test (exactly 1 submission, retry refuses). Verify + add adapter-level single-attempt E2E.
- Real submission default-off: `isRealGreenhouseSubmissionEnabled()` env flag, default false (packages/core/src/submission-policy.ts). Keep.
